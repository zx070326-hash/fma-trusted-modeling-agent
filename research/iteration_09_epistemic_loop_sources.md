# 大迭代 9：认识闭环与问题重构来源冻结

## 检索合同

- 目的：为 FMA V3 的“问题定义—证据动作—模型—决策”闭环寻找可借鉴机制，同时冻结不可外推边界。
- 范围：科学发现 Agent、主动非线性系统辨识、安全实验设计；优先原始论文和官方论文页。
- 检索日期：2026-07-22（Asia/Shanghai）。
- 数据库/入口：arXiv、JMLR、PMLR；本轮不是系统综述，也不声称穷尽相关工作。
- 权限：网页和论文只作为不可信候选知识；不能改变 Harness 权限、私有评测或晋级门。

## 来源与可借鉴机制

### S1. Co-Scientist

- Gottweis et al., *Accelerating scientific discovery with Co-Scientist*。
- arXiv:2502.18864，相关 DOI：10.1038/s41586-026-10644-y。
- 原始入口：https://arxiv.org/abs/2502.18864
- 可借鉴：持久上下文、候选假设组合、生成—批评—演化、研究目标可由科学家持续修订、外部实验验证。
- 不直接采用：以同一基础模型的自动排名/Elo 作为真实性裁决；为尚未测出单循环瓶颈而复制多 Agent 拓扑。
- 论文自报限制：开放文献漏检、负结果缺失、LLM 事实性错误、Elo 自评局限、跨领域评测不足；系统明确保持 scientist-in-the-loop。

### S2. AI Scientist-v2

- Yamada et al., *The AI Scientist-v2: Workshop-Level Automated Scientific Discovery via Agentic Tree Search*。
- arXiv:2504.08066。
- 原始入口：https://arxiv.org/abs/2504.08066
- 可借鉴：把实验经理和渐进式树搜索作为“候选研究轨迹”的搜索策略，保存失败分支而不是只保留最终稿。
- 不直接采用：把 workshop 论文接收等价为现实科学发现、机制真实性或安全性；把论文写作闭环当作建模闭环。

### S3. 主动非线性系统辨识

- Mania, Jordan, Recht, *Active Learning for Nonlinear System Identification with Guarantees*，JMLR 23(32), 2022。
- 官方入口：https://jmlr.org/beta/papers/v23/20-807.html
- 可借鉴：规划轨迹—跟踪轨迹—用全部数据重估的顺序闭环；主动动作应覆盖当前特征空间中未被激励的方向。
- 限制：保证依赖“状态—动作的已知特征嵌入、转移对其参数线性”等条件；不能推广为任意非线性系统的全局最优主动设计。

### S4. 安全学习动力系统

- Ahmadi et al., *Safely Learning Dynamical Systems from Short Trajectories*，PMLR 144, 2021。
- 官方入口：https://proceedings.mlr.press/v144/ahmadi21a.html
- 可借鉴：安全不是单个当前模型的预测，而应针对与已有数据一致的系统集合；没有安全可执行动作时必须能证明式弃权。
- 限制：主要强结论覆盖线性短轨迹及非线性单步集合表示；V3 若只使用 bootstrap ensemble 风险包络，必须称为经验代理而非安全保证。

## 冻结后的架构主张

允许进入实现的窄主张：

1. 候选假设应作为组合保存，并由独立证据更新，而不是由 LLM 自评直接晋级。
2. 建模失败可能来自问题语义、数据、模型或决策映射；Harness 必须允许证据驱动的版本化问题重构。
3. 下一步应是类型化的“认识动作”，并按预期决策价值、成本、风险和权限选择。
4. 获取更多同类数据与澄清目标/约束是可比较的竞争动作；必须在相同成本预算下消融。
5. 真实外部实验、临床/金融/安全决策仍需人工审批；本轮只运行本地合成 private WorldPack。

禁止的主张：

- V3 已经能自主发现真实世界问题；
- LLM 评委、多 Agent 辩论或论文接收证明科学正确；
- 合成问题重构收益可外推到任意数学建模任务；
- 经验不确定性包络构成形式化安全保证；
- 当前互联网检索完整覆盖了相关文献或负结果。

## 大迭代 9 的可证伪问题

在同一个稳定使命、同一个求解器、同一个初始数据、同一个一次认识动作成本和同一个隐藏决策效用下：

> 当问题契约缺失决策关键的损失语义时，V3 能否识别“继续采同类数据”的价值受限，改为取得权威语义证据、生成可追溯的子契约，并比固定契约臂降低隐藏决策 regret；同时在语义已经充分时不产生虚假重构？

只有全新确认 pack 通过预冻结宏效应、逐机制非劣、负迁移、安全权限、同预算和重放门，才允许生成范围限定的 synthetic qualification。
