# FMA Documentation Map

This directory contains the maintained architecture and protocol documents.
Versioned documents describe exact contracts and remain useful for replay and
compatibility; they are not runtime evidence or scientific authority.

## Current operating path

1. [V7 Operator Plane](architecture/V7_OPERATOR_PLANE.md) — durable intake,
   leases, fencing, reconciliation, and operator permissions.
2. [V6.8 Capability Pack Factory](capabilities/V6_8_CAPABILITY_PACK_FACTORY.md)
   — registered capability manifests, typed IR, execution, and input-bound
   verification.
3. [V6.9 Development Portfolio Lane](architecture/V6_9_DEVELOPMENT_PORTFOLIO_LANE.md)
   — multi-skeleton comparison and abstention in the development lane.
4. [V6 Graph-native Recovery](architecture/V6_GRAPH_NATIVE_RECOVERY.md) —
   diagnosis, revocation closure, bounded repair, and attempt lineage.
5. [V7.1 Native Paper Delivery](publication/V7_1_NATIVE_PAPER_DELIVERY.md) —
   evidence-bound Codex authoring, semantic review, XeLaTeX, and page review.
